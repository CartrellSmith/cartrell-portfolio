# Cartrell Smith — Portfolio

A modern, responsive, faith‑centered developer portfolio built with **React + Vite**.  
This project showcases my work as a **Frontend Engineer**, **Youth Pastor**, and **Christian Leader**, combining clean UI, accessibility, and purposeful design.

---

## 🧠 About the Project
This portfolio was built to highlight my journey as a software developer and community leader.  
It includes:

- A polished hero section with professional imagery  
- A detailed About page sharing my story  
- A Projects page showcasing real work  
- An Experience timeline  
- A Contact page  
- Full dark mode support  
- Clean blue‑and‑gold Christian‑inspired theme

## 🧩 Installation & Running Locally

```bash
# Clone the repository
git clone https://github.com/Cartrell/cartrell-portfolio.git

# Navigate into the project
cd cartrell-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
